# E18: how does search depth change the distortion, and do recursive nulls coincide across beam widths?

Draft. Commit before running. Code: `experiments/e18_depth.py` (to be written).

## Question

At depth d=2, only the round-2 anchor rule makes the menu data-dependent (e15,
E16). At d=3, round 3 always extends the round-2 winner, so even a random or
neighbor anchor re-anchors on a winner one round later. Does that partly
inflate naive type-I for rules that were nominal at d=2? And does the note's
P5, as corrected in THEORY.md, hold: does greedy search's selected value equal
the lattice maximum on nearly every replicate, so that recursive nulls
coincide across beam widths?

## Design

Searchers (K=20 features; subsets of size at most 3 unless stated):

| label | searcher | draws | note |
|---|---|---|---|
| winner | `WinnerAnchor(max_features=3)` | 1,000 | the same rule as Adaptive |
| neighbor | `NeighborAdaptive(max_features=3)` | 1,000 | bug fixed |
| random | `RandomAnchor(max_features=3)` | 1,000 | uniform random round-2 anchor |
| gumbel0 | `GumbelAnchored(tau=0, max_features=3)` | 1,000 | the same rule as random, drawn independently |
| lattice | `LatticeAdaptive(max_features=3)` | 500 | full lattice evaluated, greedy selection |
| beam16, beam4, beam2 | `BeamAdaptive(beam_width=k, max_features=3)` | 500 | e5's dose axis |
| adaptive | `Adaptive(max_features=3)` | 500 | e5's k=1 row |
| depth | `DepthAdaptive(max_features=4)` | 500 | one more round |

- Configuration: K=20, M=50, T=500, ρ=0.3 equicorrelated, s=0, sigma=1, B=1500.
- Seeds 40000–40999 for the four anchor rules; the other searchers use
  40000–40499, the first half of the same block, so every comparison between
  any two searchers is paired on the draws they share.
- `sr_sel`: each searcher's own `replay` value on the real data.
- Nulls, all with one block length (`select_block_length` on the demeaned base
  columns) and bootstrap seed = the draw's seed, so replicate `b` uses the same
  resampled time index in every null:
  - **naive:** the logged transcript;
  - **recursive:** replay;
  - **full-class:** all subsets of size at most 3, 1,350 members; at most 4
    for `depth`, 6,195 members.
- Recorded per draw: the three p-values; `sr_sel`; the round-2 anchor and its
  coupling κ where the searcher has one; block length; and the count of
  replicates whose recursive maximum equals the full-class maximum within
  1e-9 relative. Git state is captured at launch.

## Minimum detectable effect

Inflation is tested with a one-sided exact binomial test of the naive
rejection count against 5% at p < 0.05.

- At n=1,000 the test rejects at 63 or more rejections (6.3%). It has 80% power
  when the true type-I rate is **6.9%**; power is 82% at 7% and 36% at 6%.
- At n=500 it rejects at 34 or more (6.8%), with 80% power at **7.7%**.

A true rate below these can go undetected; outcome (c) below says so explicitly.

## Predictions and decision rules

1. **Identity check.** `winner` and `adaptive` give identical p-values on
   their 500 shared draws.
2. **Random-rule consistency.** `random` and `gumbel0` pick different anchors
   on each draw, so they are compared by rate, not draw by draw. Each naive
   type-I rate lies inside the other's 95% Wilson interval.
3. **Depth re-anchoring, for `neighbor` and `random` separately.** Exactly one
   of three outcomes, fixed now:
   - **(a) partly inflated:** the binomial test against 5% gives p < 0.05, and
     an exact McNemar test against `winner` (paired on 1,000 draws) finds
     significantly fewer rejections (p < 0.05, winner higher);
   - **(b) fully inflated:** the binomial test gives p < 0.05, but McNemar
     does not separate the rule from `winner`;
   - **(c) not detectably inflated:** the binomial test gives p ≥ 0.05. With
     the minimum detectable effect above, this means a true rate below roughly
     6.9% is not excluded.
   The prediction is (a) for both rules.
4. **P5's mechanism, replicate level.** For each of `adaptive`, `beam2`,
   `beam4`, `beam16` and `lattice`: the fraction of bootstrap replicates on
   which the replayed selected value equals the full-class maximum. The
   corrected P5 predicts a shortfall on about 0.2% of replicates in the
   Gaussian limit at d=3, so the threshold is **at least 99%**. Below 99% for
   any of them means P5's scope is narrower than THEORY.md states, and the
   note restricts it to d=2 or to searches without early stopping.
5. **P5's consequence, decision level.** Rejection decisions of `beam2`,
   `beam4`, `beam16` and `lattice` agree with `adaptive`'s on at least 99% of
   their 500 shared draws. The exact p-value agreement rate is reported too,
   since earlier runs showed exact coincidence, but it does not gate anything.
6. **Nominal nulls.** Recursive and full-class type-I are not significantly
   above 5% (Wilson lower bound at most 5%) for every searcher.
7. **Dose axis.** Naive type-I across lattice → beam16 → beam4 → beam2 →
   adaptive is nondecreasing, as in SCOPE.md §5, now at n=500 with the anchor
   bug fixed.
