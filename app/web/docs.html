quixote example

This audits a bundled log, a scripted searcher's moves on a small synthetic panel, and prints the verdict. Every verdict on this site comes with the command that reproduces it, for example:

quixote audit examples/logs/scripted_session.json --panel examples/data/tiny_panel.npz --class examples/class.json --B 2000 --seed 0 --json

What a verdict means

PASSp is below α: the submitted rule beats what the search would find on noise.
FAILp is at or above α, and the test had the power to tell: the result is what this search finds by luck.
INADMISSIBLEp is at or above α, and the search was too wide to certify anything.
UNDECIDABLEthe record alone cannot license a correction.
DEGENERATEthe test statistic broke on this menu. Do not read its p.

The code reports a pass as CERTIFIED; this site shows it as PASS.

How this site runs it

Nothing is computed on a server. Your browser downloads Python (Pyodide 314.0.7), numpy and pandas, and the observable-garden package built from the repository's own source, all served from this site with their hashes recorded. A Web Worker runs quixote.audit.audit_log, the function behind quixote audit. Two functions the package takes from compiled libraries are replaced in the browser only, by ports held equal to the originals by tests: the Politis–White block length (from arch) and the normal distribution functions (from scipy). An equivalence test runs the browser build against the command line on every example.

The record on a result

The config hash is the SHA-256 of the JSON object (keys sorted, no spaces) {"B", "alpha", "class_sha256", "log_sha256", "panel_sha256", "seed", "wheel"}: the inputs' hashes, the replicate count, the seed, α and the exact package build.

Recorded replays (format)

Searches too large for a browser, such as the 82,240-member ETF class, will be shown as recorded replays: a run made locally with the package, played back here. A recording is one JSON file:

{
  "format": "quixote-replay/1",
  "log": { ...the quixote-log/1 file the harness wrote... },
  "result": { ...quixote.audit.AuditResult.to_dict(), plus "replicate_paths" if exported... },
  "package": "observable_garden-0.1.0+g<commit>-py3-none-any.whl",
  "command": "quixote audit ... --json",
  "pace": { "search_ms": 6000, "null_ms": 8000,
            "progress": [ { "t_ms": 0, "stage": "class", "done": 0, "total": 2000 }, ... ] }
}
