Sancho · the fixed model

Sancho

Sancho does not run on this site. Its model uses LightGBM, which has no browser build, and a re-implementation would not be the registered Sancho. It runs on your own machine with the package. This page is where you tailor it and read its results: set the levers, download the config, copy the command, and open what it writes in the Viewer.

What Sancho is

Sancho is the fixed model the agents are compared against: one prediction model, declared in advance, that counts as a single strategy, so the gate can test a non-linear strategy at the price of one trial. Its design (the penalty grids, the training windows) was settled on synthetic returns, without the returns of any panel it was later tested on. Every real test was registered first, and its stream is built walk-forward: refit every 252 rows on past rows only, with an embargo of h + 1 + d rows between the training rows and the row scored. Inside, ridge regressions and small gradient-boosted trees (LightGBM, depth 2) over price, cross-asset and volume inputs, stacked with non-negative weights.

The levers

Every lever Sancho has is in one file, sancho/config.json; the defaults are the registered version 2, and the registered results apply to the default only. Change any lever below and the page writes the file quixote sancho reads, with its config hash. Nothing you set here leaves this page or is stored.
