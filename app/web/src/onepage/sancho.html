Why, and what this section does

Sancho's model uses LightGBM, which has no browser build, and a re-implementation would not be the registered Sancho. Use this section to set the levers, download the config and copy the command. Then open the output in the viewer, at the end of this section.

What Sancho is

Sancho is the fixed model that agents are compared against. It is one prediction model, declared in advance, so it counts as a single strategy. That lets the gate test a non-linear strategy at the cost of one trial.

How it was designed and how its stream is built

Its design (the penalty grids and training windows) was settled on synthetic returns, never on the returns of a panel it was later tested on. Every real test was registered first. Its stream is built walk-forward: it refits every 252 rows on past rows only, with an embargo of h + 1 + d rows between the training rows and the row scored. Inside are ridge regressions and small gradient-boosted trees (LightGBM, depth 2) over price, cross-asset and volume inputs, stacked with non-negative weights.

The levers

All of Sancho's levers are in one file, sancho/config.json. The defaults are the registered version 2, and the registered results apply only to those defaults.

What changing a lever does

Change any lever below and this page writes the config file that quixote sancho reads, with its hash. Nothing you set here is stored or leaves the page.
