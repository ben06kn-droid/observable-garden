Install #

git clone --depth 1 https://github.com/ben06kn-droid/observable-garden
pip install -e .                  # Python 3.10 or later

One minute #

quixote example

This audits a bundled log, a scripted searcher's moves on a small synthetic panel, and prints the verdict. Every verdict on this site comes with the command that reproduces it, for example:

quixote audit examples/logs/scripted_session.json --panel examples/data/tiny_panel.npz --class examples/class.json --B 2000 --seed 0 --json

The panel format #

A panel is one .npz file (quixote/panel.py); quixote run, quixote audit and quixote sancho all read it.

arrayshape
returns(T, M)simple returns; NaN = not tradable in that row
features(T, M, K)what a rule may use in row t (data up to row t only)
feature_names(K,)
periods_per_yearscalar252 for daily rows
delayscalar, default 1features at row t earn returns[t + 1 + delay]
cost_bpsscalar, default 5one-way cost per unit of turnover
borrow_bps_yrscalar, default 50borrow on short weight, a year
row_labels, asset_names(T,), (M,)optional; split accepts a row label

A rule's book is dollar-neutral at gross 1 over the tradable assets; quixote.panel.save(...) writes the file. Sancho reads the same file: it builds its return-structure block from returns, uses features as its 40 registered features only when K is 40, and needs a few years of rows (its first scored row is 763 with the default levers).

What a verdict means #

PASSp is below α: the submitted rule beats what the search would find on noise.
FAILp is at or above α, and the test had the power to tell: the result is what this search finds by luck.
INADMISSIBLEp is at or above α, and the search was too wide to certify anything.
UNDECIDABLEthe record alone cannot license a correction.
DEGENERATEthe test statistic broke on this menu. Do not read its p.

The code reports a pass as CERTIFIED; this site shows it as PASS.

How this site runs it #

Nothing is computed on a server. Your browser downloads Python (Pyodide 314.0.7), numpy and pandas, and the observable-garden package built from the repository's own source, all served from this site with their hashes recorded. A Web Worker runs quixote.audit.audit_log, the function behind quixote audit. Two functions the package takes from compiled libraries are replaced in the browser only, by ports held equal to the originals by tests: the Politis–White block length (from arch) and the normal distribution functions (from scipy). An equivalence test runs the browser build against the command line on every example.

The record on a result #

The audit id is the SHA-256 of the JSON object, keys in code-point order and no spaces, {"B", "alpha", "class_sha256", "log_sha256", "panel_sha256", "seed", "wheel"}: the inputs' hashes, the replicate count, the seed, α and the exact package build. Two runs with the same audit id price the same search on the same data with the same code. (Sancho's config hash is a different thing: the hash of its lever file, shown on the Sancho page and by the viewer, opened from it.)

The paper: The Observable Garden: fixed and adaptive candidate sets under the DSR #

Knaster (2026). On SSRN: papers.ssrn.com/sol3/papers.cfm?abstract_id=7616559.

A backtest is usually the best of many attempts, so its Sharpe ratio has to be judged against what the best of many attempts would find on pure noise. When the search is adaptive, testing against the list of strategies it happened to try gives the wrong error rate. A class of strategies declared before the search, or a log of every decision that can be re-run on noise, restores a valid test. Quixote is the gate built on that answer.

Where it stands #

The gate keeps its error rate in every registered test; its limit is power. On real data it refused nearly everything, including 240 LLM agent sessions on liquid ETFs, and issued one certificate, on a long history of industry portfolios, whose lower bound held on the six years that followed. It is evidence that the gate works, not a source of trading signals.
