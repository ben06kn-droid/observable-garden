Run your own agent

Your model as the agent

Bring a data panel, a class of rules, an API key and a budget. Your model runs the search here in your browser, and the gate tests what it finds.

What the model sees, and where your files and key go

Your panel and class files are read in this page and never uploaded. Your key goes from this page straight to the provider. The model receives the prompt and tools below, plus what the harness shows any agent: the feature names, the class name, the rule it holds, the scores of the rules it tries, the stopping-rule information and the move budget. It never sees the returns or the feature values. You get a log the command line can audit, and a verdict you can download or share.

Key

03Key

Your key is held in this page's memory for one run and sent only from your browser to the provider. It is never stored and never appears in a URL, the log or the result. It is cleared when the run ends or you leave the page.

You can verify this. Open your browser's developer tools, Network tab, during a run: the only hosts contacted are this site and api.anthropic.com. The site's content security policy allows connections only to this site, api.anthropic.com, api.openai.com, openrouter.ai, and localhost or 127.0.0.1 on any port. It forbids the browser from sending anything to any other destination. The code that handles the key is public: app/web/src/gate.worker.ts.

Use a key you can delete afterwards.
