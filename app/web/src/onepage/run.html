What the model sees, and where your files and key go

Bring a panel and a class, your API key and a budget. The harness runs your chosen model as the agent through the same search the demo shows, here in your browser, and the gate prices it. You get a log the command line can audit, and a verdict you can download or share. Your panel and class files are read in this page and never uploaded. The model receives the prompt and tools below and what the harness shows any agent: the feature names, the class name, the rule it holds, the scores of the rules it tries, the stopping-rule information and the move budget; not the returns or the feature values. Your key goes from this page straight to the provider.

Model

02Model

Sent to the Messages API as output_config.effort. Every level the provider documents is offered for every model; a model that refuses one answers with the provider's error, shown word for word.

Ollama, LM Studio, vLLM or any server that speaks chat completions, on this computer. The server must allow this site's origin (for Ollama, set OLLAMA_ORIGINS to include it), and your browser may ask whether this site may reach devices on your local network. The model must support tool calls.

Key

03Key

Held in this page's memory for one run, sent only from your browser to the provider, never stored, never in a URL, the log or the result, and cleared when the run ends or you leave the page.

You can verify this: open your browser's developer tools, Network tab, during a run; the only hosts contacted are this site and api.anthropic.com. The site's content security policy allows connections only to this site, api.anthropic.com, api.openai.com, openrouter.ai, and localhost or 127.0.0.1 on any port, and forbids the browser from sending anything to any other destination. The code that handles the key is public: app/web/src/gate.worker.ts.

Use a key you can delete afterwards.
