The Observable Garden

Did the agent find an edge, or just search long enough?

When an AI agent searches market data, its best backtest always looks good, because it is the best of many tries. Quixote records every step of the agent’s search, replays it on null data, and certifies a strategy only if it beats what the search would find by luck.

Run it on your own search, read the docs, or read the paper.
