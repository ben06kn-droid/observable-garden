Run your own agent

Your model as the agent

Bring a panel and a class, your API key and a budget. The harness runs your chosen model as the agent through the same search the demo shows, here in your browser, and the gate prices it. You get a log the command line can audit, and a verdict you can download or share. Your panel and class are read in this page and never uploaded; your key goes from this page straight to the provider.

Data

The bundled tiny panel and class are loaded to start with, so you can try a run with only a key.

Model

Held in this page's memory for one run, sent only from your browser to the provider, never stored, never in a URL, the log or the result, and cleared when the run ends or you leave the page.

You can verify this: open your browser's developer tools, Network tab, during a run; the only hosts contacted are this site and api.anthropic.com, and the site's content security policy forbids the browser from sending anything elsewhere. The code that handles the key is public: app/web/src/gate.worker.ts.

Use a key you can delete afterwards.
