Run your own agent

This page will let you upload a panel and declare a class, paste your own API key, and drive a language-model agent through the gate, all in your browser: the key goes from your browser straight to the provider, and the panel is read here, never uploaded.

Until then, run it locally: quixote run --agent mymodule:MyAgent --panel my.npz --class my_class.json --out log.json, then quixote audit. See Docs.
