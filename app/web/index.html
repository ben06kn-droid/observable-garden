The Observable Garden

A backtest is the best of many attempts.

Quixote is an overfitting gate for strategies found by AI agents. It logs every rule an agent tries, re-runs the same search on noise, and certifies the rule it submitted only if it stands above what that search finds by luck. Here it runs entirely in your browser.

A search is every rule an agent scored on its way to the one it kept. Each evaluation is another chance to find a high Sharpe ratio by luck, so a longer search sets a higher bar: the best of thirty tries means less than the best of three, and the best of three hundred less again. When the search adapts, choosing what to try next from what it has seen, the bar depends on how it searched, not only on how much.

So the gate re-runs the logged search, move for move and under the rules it declared, on copies of the data with every rule's edge taken out. What those searches find is what this one finds by luck. The submitted rule passes only if it stands above them; otherwise the result is what any such search would have found on noise.

Here you can run the gate on three bundled searches, watch each one grow and be priced, and go inside any tree to see every rule it tried. Later you will be able to bring your own class of strategies and your own agent. The method and the results are in the paper.

  1. 01 The searchThe agent names a move; the harness performs it and logs every rule it scores.
  2. 02 The nullThe logged search is re-run on resampled, edgeless copies of the data.
  3. 03 The verdictPass, fail, or a refusal, with the lower bound after the search is paid for.
  4. 04 The recordEvery number comes back from one command line, from the same code.
