An overfitting gate for strategies found by AI agents

A backtest is the best of many attempts.

Quixote logs every strategy an agent tries, re-grows the same search on noise, and certifies the one it submitted only if it stands above what that garden grows by luck.

Run the demo Run your own

01The search

The agent names a move. The harness runs it.

An agent never hands in a rule it built. It names one move, and the harness performs it against a class of strategies declared before the search, scores every candidate the move considers, and writes all of it to the log. The log cannot disagree with what ran, because the log is what ran.

The search grows in daylight. Each bud is one evaluation, drawn at the height of its in-sample Sharpe; a move fans out to every candidate it scored, the one it keeps grows on, and a restart is a new stem. Each mode grows its own species: the demo an oak, your own agent a baobab, Sancho a bonsai.

initanchor on the best single feature: the trunk
extend_bestadd the feature that most improves the held rule
swap_worstreplace the weakest held feature
flipreverse one held feature's sign
restartonly on a declared rule that fires: a new stem
stoponly on a declared rule that fires

02The null

At night the garden is re-grown on noise.

The gate resamples the rows of the data, removes every rule's average return so none has an edge, and re-executes the logged search on each copy: the same moves, the same declared stopping rules. Where a copy's search would run on, it continues with the best one-step move.

Each copy keeps the best rule it reaches. The p-value is the share of copies that reach the submitted Sharpe. On the first demo example, p of B: nearly every search on noise did at least as well.

03The verdict

One of five answers.

Beside it, the lower bound L0.90: the Sharpe the selected rule is 90% confident of exceeding, after the search is paid for.

04The record

Every run reproduces from one command.

The class is hashed before the first evaluation and the hash goes into the log, so a class changed after results are seen is refused. The panel's hash, the seeds, the model and the budget go in beside it. Any verdict here comes back from the command line, from the same code.
